## Nick's TMUX Config

Clone this repo:
```zsh
git clone https://github.com/NOM1989/tmux.git ~/.config/tmux
```

Symlink config to home directory:
```zsh
ln -s ~/.config/tmux/.tmux.conf ~/.tmux.conf
```

Install TPM
See: [https://github.com/tmux-plugins/tpm#installation](https://github.com/tmux-plugins/tpm#installation)

You're good to go!
